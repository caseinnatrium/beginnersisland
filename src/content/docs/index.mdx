# Welcome to Beginner's Island

Welcome to the **Beginner's Island** fanpage!

This site is a fan-made archive for **DBLOTS Beginner's Island (Rookgard)**, featuring information about **items, monsters, and locations**. It also includes useful **guides** and a **high scores** section. Majority of the guides has been written from perspective of person staying on the island, hence there are differences between sections available on official website, forums and this database.

To get to the island you need to use command !skip while at level 1 in the Tutorial Island area. You cannot level up and you ought to have a character that already finished tutorial on the acocunt.

The site is still being developed, and some links may not yet be fully functional. It had been mostly vibe coded using free LLMs.
If you notice an error or have something to report, feel free to [send me a message](http://dblots.pl/privmsg.php?mode=post&u=101579).
