Helper is the only NPC found on Beginners Island. He provides basic information for new players and offers a small selection of trades and tasks.

## Trades

Helper buys Animal Fur for 5 silver zeni, Bullet for 15 silver zeni, and Army Piece of Cloth for 30 silver zeni. He sells Oil for 10 credit cards.

## Tasks

Helper responds to the `task` keyword and can display all available tasks with `task all`.

## Quick Reference

| Keyword | Function |
|---|---|
| `hi` | Start conversation |
| `help` | Learn about Helper and leaving Beginners Island |
| `job` | Learn Helper's role |
| `quest` | Ask about quests |
| `offer` | View Helper's trade offers |
| `task` | Ask about recommended tasks |
| `task all` | Display all available tasks |
| `task Animals` | Select the Animals task |
| `task Weremals` | Select the Weremals task |
| `task Robbers` | Select the Robbers task |
