## Task Titles

Completed tasks count toward task titles. Each title provides an additional task-related bonus.

| Title | Tasks Completed | Bonus |
| --- | ---: | --- |
| **Tasks Beginner** | 10 | 5% more experience for task |
| **Tasks Advanced** | 25 | 10% more experience for task |
| **Tasks Master** | 50 | 15% more experience for task |
| **Tasks Maniac** | 100 | 20% more experience for task |
| **Tasks Expert** | 250 | 0.1% chance to respawn [Rich Monster](/systems/monsterpower/) |
| **Tasks Dominator** | 500 | 0.2% chance to respawn [Rich Monster](/systems/monsterpower/) |

## Task Bosses

Task bosses are listed in the [monster catalogue](/monsters/).

Stage 2 rewards **5× Permission to fight** the corresponding task boss.


## Total Rewards

Completing task daily provides one with 9 BP and 140 000 experience points, as well as 5 permissions to kill the boss.
:::note
Boss-kill permissions are task-specific: they can accumulate when repeatedly completing the same task, but accepting a different task causes the accumulated permissions for the previous task to be forfeited
:::
